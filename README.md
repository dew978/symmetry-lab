# 대칭 실험실

삼대710 제작. 초등학교 5학년 선대칭·점대칭 학습 도구입니다.

- **대칭 완성하기**: 반쪽 도형을 만든 뒤 접기 또는 180° 회전으로 대칭도형을 완성합니다.
- **실시간 대칭 그리기**: 점과 선분을 그리면 반대쪽에도 동시에 표시됩니다.
- 20×20 모눈, 자유 기울기 대칭축, 점 이동, 두 번 눌러 삭제, 되돌리기, 전체화면을 지원합니다.

## 실행 및 배포

별도의 빌드나 서버 기능 없이 HTML·CSS·JavaScript로 동작합니다.
GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포 대상으로 설정합니다.

## 파일

- `index.html`: 화면 구성
- `style.css`: 디자인
- `app.js`: 도구·편집·애니메이션
- `geometry.js`: 대칭과 점 연결 계산
